# TFortisTestBuilder

Приложение Avalonia/.NET 8 для создания и выполнения производственных проверок
коммутаторов и плат. Инженер собирает граф, оператор запускает сохранённый
профиль в пульте. Документация сверена с исходниками 28 октября 2026 года;
[область проверки и ограничения](docs/obsidian/13%20-%20Карта%20актуальности.md).

## Запуск и сборка

Нужен .NET 8 SDK. Из корня репозитория:

```sh
dotnet restore TestBuilder/TestBuilder.csproj
dotnet build TestBuilder/TestBuilder.csproj
dotnet run --project TestBuilder/TestBuilder.csproj
dotnet test TestBuilder.Tests/TestBuilder.Tests.csproj
```

Для полного производственного сценария используется Windows. Npcap нужен для
DataTest, повышенные права — для настройки сетевых адаптеров и очистки ARP,
Windows spooler — для RAW-печати. WinSCP и bat-файлы копируются вместе с приложением.
Проверки UI и значительной части runtime можно выполнять на macOS без стенда.
Сборка/тесты сами по себе не подтверждают аппаратный результат.

[Быстрый старт](docs/obsidian/01%20-%20Быстрый%20старт.md),
[сборка комплекта Windows](packaging/windows/BUILD.md).

## Работа

1. «Подключиться» занимает COM-порт: пустое поле «COM стенда» означает перебор
   по имени, явно заданный порт — только его. Ответ Modbus пока не проверяется.
2. При открытии профиля проверяется его оборудование на занятом порту.
3. Автоматически выполняются начальные ноды «При открытии профиля».
4. После успешной подготовки основной тест запускается вручную. Следующие
   изделия не требуют повторять подготовку до нового открытия профиля.

Профиль можно выбрать до подключения; тогда проверка и подготовка начнутся
после подключения. Автономный граф без аппаратных требований работает без COM.
[Подробности подключения](docs/obsidian/07%20-%20Modbus%20и%20мониторинг.md).

В интерфейсе доступны:

- редактор графов с вложенными подтестами, циклами, параллельными ветвями,
  частичным запуском, редактированием мышью и необязательными названиями нод;
- копирование/переименование профиля через ПКМ, каталог оборудования и свои
  карты Modbus, консоли UART, изображения и области плат;
- кнопки профиля с мини-графами, переключателем или индикатором выполнения;
- таблица сетевых пар DataTest и отдельный редактор сетевых карт;
- вкладка пробной печати с шаблонами, SN/MAC, количеством и повтором этикетки;
- журнал с остановкой слежения для чтения старых строк, темы и автоматическое
  сохранение расположения панелей, фильтров и размеров. Алгоритм сохраняется вручную.

Офлайн-справка: **Настройки → Полная инструкция**. В ней 54 статьи, включая
32 справки по нодам и служебным границам. Есть поиск, копирование и HTML-экспорт.
[Инструкция для первого знакомства](docs/obsidian/24%20-%20Инструкция%20для%20первого%20знакомства.md).

## Профили

В `profiles` находятся шесть поставляемых профилей: PSW-2G6F+, три варианта
PSW+UPS-Box 8x2Pro, RTL-SW и RTL-PoE. Они копируются при build/publish.
Примеры и демонстрации находятся в `examples/profiles` и импортируются отдельно.
Профили сохраняют граф, названия модели/конфигурации, оборудование, плату и кнопки.

Вариант 8x2Pro «параллельный старт · без проверки SFP» проверяет только медные
порты. Название «полная проверка» само по себе не подтверждает полноту методики.
Состав и ограничения: [PSW-2G6F+](docs/obsidian/20%20-%20PSW-2G6F+%20тестирование.md),
[8x2Pro](docs/obsidian/21%20-%20PSW+UPS-Box%208x2Pro%20тестирование.md),
[RTL-SW/PoE](docs/obsidian/25%20-%20Перенос%20TFortisBoard%20в%20TestBuilder.md).
