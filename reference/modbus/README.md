# Карты Modbus и базовый состав АПК-03

`hardware-presets.json` — общие шаблоны отдельных устройств для каталога,
поиска оборудования и автономной справки нод. Этот же файл встраивается
в приложение как резерв при отсутствии внешнего файла.

`stand-apk-03.json` — полное описание оборудования, которое можно загрузить
через **Оборудование → Импорт оборудования…**, проверить, применить и сохранить
в профиле. Импорт заменяет весь черновик, включая консоли; он не применяется
автоматически при открытии старого профиля.

## Приоритетный источник

Пользовательский документ от 19.11.2026 сохранён без изменения:
[Карта регистров СТЕНД-АПК-03.docx](../../docs/references/modbus/Карта%20регистров%20СТЕНД-АПК-03.docx).
Построчная выгрузка адресов, RO/RW и назначений для регрессионной сверки:
[stand-apk-03-registers-2026-11-19.json](../../docs/references/modbus/stand-apk-03-registers-2026-11-19.json).

| Название шаблона | Название в документе | Регистров | Диапазоны Holding |
| --- | --- | ---: | --- |
| EL-60v5 | EL-60 | 23 | 1400–1403, 1412–1430 |
| IO-2 | IO-02 | 30 | 1500–1529 |
| PS-3 | PS-03 | 7 | 1200–1201, 1215–1216, 1219–1221 |
| SIMBAT-24 | SIMBAT-24 | 13 | 1700–1702, 1705–1708, 1711–1716 |

Имена шаблонов и значения идентификации сохранены для совместимости с
местными настройками поиска. Старая EL-60 с адресами 1000–1016, SIMBAT-48,
PS-1/PS-2 и другие устройства остаются отдельными заготовками; они не входят
в новый целевой состав документа. Специальный порядок сортировки из пожеланий
автора документа не вводится; поиск регистра сохраняет сортировку по адресу.

В целевом составе восемь EL-60v5 занимают нечётные Slave 1–15, две SIMBAT-24 —
17 и 19, IO-2 — 21, PS-3 — 23. На ещё не переоборудованном стенде может
оставаться SIMBAT-48; импорт не меняет физическую плату или её прошивку.

Документ определяет адреса, назначения, RO/RW, состав и функцию 03. Он не
задаёт параметры линии и значения регистра идентификации. В базовом JSON
оставлены настройки программы: 9600/8N1, опрос 1000 мс, типы 4/9/5/8 по
адресу 0. Их следует сверить с фактическим стендом. Существующий масштаб
измерений SIMBAT сохранён; таблица источника не задаёт единицы этих значений.

Обновление шаблонов не переписывает карты в уже сохранённых профилях или
пользовательском `equipment-library.json`. Перед заменой состава сохраните
экспорт прежнего оборудования и проверьте используемые нодами адреса.
