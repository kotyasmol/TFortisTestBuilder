TFortisTestBuilder 1.0.0 — Windows 10/11 x64

ПЕРВЫЙ ЗАПУСК
1. Распакуйте ВЕСЬ архив в папку с правом записи, например C:\TFortisTestBuilder.
   Не запускайте exe прямо из ZIP и не переносите только один exe.
2. Запустите Check-Installation.cmd. Результат — installation-check.txt.
3. Запустите Start-TestBuilder.cmd или TestBuilder.exe.
4. Для знакомства выберите «Демонстрация пульта · без оборудования».
   Для настоящего теста настройте стенд, драйверы и сервер, как описано ниже.

ВКЛЮЧЕНО В КОМПЛЕКТ
• Приложение Release 1.0.0 и .NET 8 x64: установка .NET/SDK не требуется.
• Все используемые управляемые и native-библиотеки из NuGet.
• Переносимый Chrome for Testing для headless selftest, без установки браузера.
• WinSCP, set_mac_pro.bat и arpd.bat для алгоритмов стенда.
• Все 6 актуальных профилей: PSW-2G6F+, три 8x2Pro (последовательный,
  параллельный старт, параллельные циклы EL60), ручная печать, демонстрация.
• Документация проекта, сведения о зависимостях и доступные тексты лицензий.
• release-manifest.json с составом и SHA-256 каждого исходного файла.
  Изменённые оператором профили/настройки будут отмечены проверкой отдельно.

ЧТО ОСТАЁТСЯ НАСТРОИТЬ НА НОВОМ КОМПЬЮТЕРЕ
Это автономное приложение, но драйверы Windows нельзя заменить копированием
DLL в папку. До полного производственного теста необходимы:

• Npcap для DataTest. Установщика в комплекте нет: свободная редакция не
  разрешает включение в чужой дистрибутив, OEM-установщик не предоставлен.
  Официальная загрузка/условия: https://npcap.com/#download
  Руководство установки: https://npcap.com/guide/npcap-users-guide.html
  Для установки нужны права администратора. При выборе Npcap учитывайте
  ограничения лицензии на число установок и режим доступа к драйверу.
• Драйвер USB–RS-485/COM для фактически используемого адаптера, если его
  не установила Windows. Модель адаптера пока не указана; драйвер не включён.
• Драйвер и очередь принтера TSC TE310 (или имя вашего принтера в профиле).
  Драйвер принтера не включён; RAW-печать использует установленную очередь.
• IP-адреса и привязка сетевых карт DataTest на этом компьютере. Настройка
  выполняется в инженерном режиме приложения. Для изменения сети и очистки
  ARP могут потребоваться права администратора. Привязки со старого ПК
  намеренно не перенесены: идентификаторы адаптеров на новом ПК другие.
• Фактический Stand ID вместо исходного 123 и доступ к серверу
  https://iccid.fort-telecom.ru. Рабочую сессию передаёт корпоративный лаунчер:
      TestBuilder.exe SESSION_ID "Имя оператора"
  Либо: TestBuilder.exe --session SESSION_ID --user "Имя оператора"
  Лаунчер и учётная запись сервера не входят в этот репозиторий/архив.

ПРОШИВКА PSW-2G6F+
Файл не был предоставлен. По согласованию сохранён исходный путь профиля:
C:/FortTelecom/Launcher/TFortisStandNew/firmwares/sw407/sw407-0.2.13-05.09.2025.img
Скопируйте нужный образ туда со старого стенда, если требуется обновление.
Когда версия DUT уже подходящая, штатный шаг может пропустить обновление;
при необходимости обновления отсутствие файла завершит шаг ошибкой.
Профили 8x2Pro на этот файл не ссылаются.

НАСТРОЙКИ И ЛОГИ
testbuilder.settings сохраняется рядом с exe. Файловые логи включены и идут
в logs; папка создаётся при работе. При первом запуске profiles определяется
рядом с exe. Сохраняйте папку в доступном для записи месте. Перед заменой
релиза скопируйте свои profiles, testbuilder.settings и logs отдельно.
Не накладывайте релиз поверх старой папки: распакуйте в новую и перенесите
нужные настройки/профили осознанно.

ПРОВЕРКА РЕЛИЗА
Сборка выполнена для win-x64 на macOS; проверены автоматические тесты,
структура публикации, профили и контрольные суммы архива. Запуск самого
Windows exe, скрипта проверки и физического стенда на чистой Windows здесь
не выполнялся. Проверка готовности не заменяет первый стендовый прогон.
