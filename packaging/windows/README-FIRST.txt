TFortisTestBuilder — Windows 10/11 x64
Версия и дата сборки указаны в release-manifest.json.

ЗАПУСК С ФЛЕШКИ
1. Скопируйте ZIP на компьютер и распакуйте ВЕСЬ архив в отдельную папку,
   например C:\TFortisTestBuilder. Папка должна быть доступна для записи.
2. Запустите Start-TestBuilder.cmd или TestBuilder.exe внутри этой папки.
   Устанавливать .NET, SDK или браузер для приложения не нужно.
3. В пульте выберите профиль нужного изделия. Список групп сначала свёрнут.
4. Подключите стенд по USB, включите питание стенда и нажмите «Подключить».
   Видимый COM-порт ещё не означает, что питание стенда включено.
5. Нажмите «Запустить» и следуйте инструкциям на экране.
   Полная инструкция и интерактивное обучение находятся в настройках.

Не запускайте приложение прямо из ZIP и не переносите отдельно один EXE.
Для обновления распакуйте архив в новую папку. Сохраните изменённые профили,
настройки и логи предыдущей версии, если они нужны.

ЧТО ВКЛЮЧЕНО
• Приложение с .NET 8 x64 и необходимыми библиотеками.
• Шесть профилей: RTL-SW, RTL-PoE, PSW-2G6F+ и три варианта 8x2Pro
  (последовательный, параллельный старт, параллельные циклы EL60).
• Картинки SW/PoE, области подсветки, привязки к нодам и карты оборудования
  находятся внутри JSON-профилей. Искать изображения на другом компьютере
  или указывать путь к ним не требуется.
• Параметры Modbus и автоматического подключения к стендам плат уже заданы.
  Для SW настроен поиск процессора DUT через CH340 после его старта;
  заранее выбирать ещё не появившийся USB-UART порт не требуется.
• Встроенная инструкция, обучение, переносимый Chrome for Testing, WinSCP,
  arpd.bat и set_mac_pro.bat. Документация и лицензии лежат рядом с приложением.
• Базовые настройки: пульт, светлая тема, автоматический поиск COM,
  поставляемая папка profiles, файловые логи и адрес производственного сервера.

ПРОФИЛИ ПЛАТ
Прошивка плат, внешняя утилита чтения MCU ID, печать и отправка отчёта
в поставляемых профилях SW/PoE выключены. Обычные проверки сохранены.
Получение серийного номера с производственного сервера остаётся включённым:
для этого этапа нужна действующая сессия корпоративного лаунчера.
К5 проходит все пять режимов при обычных неудачных измерениях. После отказа
блока выполняется снятие питания. Потеря связи, отмена или исключение
прерывают основной тест и запускают завершающие действия.
Если отключение не подтверждено, новый запуск блокируется. Выключите питание
стенда и обратитесь к инженеру; порядок проверки описан во встроенной справке.

ЧТО ЗАВИСИТ ОТ КОНКРЕТНОГО КОМПЬЮТЕРА
• COM: Windows должна видеть адаптер стенда и, для SW, USB-UART DUT после
  старта платы. Если драйвер не установлен, нужен драйвер производителя
  соответствующего адаптера. Он не заменяется библиотеками программы.
• Для DataTest коммутаторов нужны установленный Npcap и привязки сетевых
  карт этого компьютера. Карты выбираются в инженерном режиме приложения.
  Для проверки плат SW/PoE Npcap и настройка сетевых карт не требуются.
  Npcap не включён в архив; официальный сайт: https://npcap.com/#download
• Для получения серийных номеров и производственных отчётов нужны доступ
  к https://iccid.fort-telecom.ru и сессия корпоративного лаунчера:
      TestBuilder.exe SESSION_ID "Имя оператора"
  Либо: TestBuilder.exe --session SESSION_ID --user "Имя оператора"
  Лаунчер и учётные данные не входят в комплект. Сессия не хранится в JSON.
  Для отправки отчётов укажите фактический Stand ID вместо исходного «тест».
• Для включённой печати нужна установленная очередь принтера с именем,
  заданным в профиле (по умолчанию TSC TE310).
• Прошивка PSW-2G6F+ отсутствует в репозитории. Если профиль потребует
  обновления, нужен файл со старого стенда по сохранённому пути:
  C:/FortTelecom/Launcher/TFortisStandNew/firmwares/sw407/sw407-0.2.13-05.09.2025.img
  Это относится к коммутатору; прошивка плат SW/PoE выключена.

ПЕРЕНОС ПРОФИЛЕЙ И НАСТРОЕК
profiles содержит JSON-профили. Изображения и оборудование плат включены
в соответствующий JSON. Сохраните профиль в редакторе и скопируйте его JSON
из папки profiles на другой компьютер. Там используйте «Импорт» либо
положите JSON в profiles; копирование всей папки сохраняет комплект целиком.
testbuilder.settings рядом с EXE содержит настройки программы. Начальный
путь profiles определяется автоматически, без привязки к букве флешки.
Логи тестов пишутся в logs рядом с EXE. Диагностика ошибок находится также
в %LOCALAPPDATA%\TestBuilder\logs. При ошибке передайте журнал проверяющему.

ПРОВЕРКА КОМПЛЕКТА
Check-Installation.cmd проверяет файлы по контрольным суммам и показывает,
какие внешние компоненты доступны. Результат: installation-check.txt.
Предупреждения о Npcap, сетевых картах или принтере относятся только к тем
проверкам, которые их используют. Проверка не меняет сеть и не включает стенд.
release-manifest.json содержит версии и контрольные суммы файлов.

Сборка выполнена на macOS для Windows x64. Комплектность и архив проверены.
Запуск EXE на Windows и физический стенд в этой среде не проверялись.
