# Диагностика 8x2Pro на стенде

Только Windows и штатный `PSW+UPS-Box 8x2Pro · Параллельная проверка с SFP · 11.11.26.json`.
Запуск действительно управляет подключённым оборудованием; требуется
разрешение оператора. Перед запуском освободить COM-порт, остановив приложение.

```powershell
dotnet build tools/BenchProbe/BenchProbe.csproj -c Release
dotnet tools/BenchProbe/bin/Release/net8.0/BenchProbe.dll profiles/PSW+UPS-Box 8x2Pro · Параллельная проверка с SFP · 11.11.26.json COM3 --execute-8x2pro hardware 1
```

Режим `hardware` выполняет штатные подтесты подготовки, настройки PoE,
питания, selftest, нагревателей, медного DataTest и UPS, затем десять
повторных selftest. Режим `selftest` оставляет подготовку, питание,
ожидание загрузки и двенадцать чтений selftest. Последний аргумент — число
циклов (1–10); в конце каждого цикла питание выключается и проверяется.

Используются реальные GraphCompiler, TestExecutor, ModbusService и
RegisterMonitor. Параметры и допуски берутся из JSON. SFP выключен только
в памяти этого процесса. JSON и его расположение не сохраняются.
Серийник, запись MAC, этикетки и отправка производственного отчёта не запускаются.
Это диагностика выбранных аппаратных этапов, не полный производственный выпуск.

Chrome/Edge выбирается как в приложении: сначала `Browser/chrome-win64/chrome.exe`
рядом с диагностическим exe, затем установленный Chrome/Edge. Для воспроизводимости
использовать тот же комплект Browser, что и на исследуемой машине.

Ctrl+C отменяет текущую проверку, затем выполняется аварийное выключение
профиля, сброс PoE-нагрузок и чтение AC1/AC2, нагревателей и ключа SIMBAT.
При ошибке любой проверки или выключения следующий цикл не начинается.
`CLEANUP_CONFIRMED` подтверждает прочитанные выключенные выходы;
`BENCH_PROBE_SUCCESS` — успех всех выбранных проверок.
