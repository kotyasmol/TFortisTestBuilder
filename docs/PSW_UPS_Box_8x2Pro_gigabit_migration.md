# Проверка двух гигабитных портов 8x2Pro

Запрос: проверить два гигабитных порта в действующих профилях.

| Этап | Источник и решение | Параметры | Отказ | Проверка |
| --- | --- | --- | --- | --- |
| DataTest SFP 8–9 | Сверка модели в Obsidian 21 указывает SFP на индексах 8/9; текущий профиль связывает их с .10/.11. Явный запрос пользователя включить гигабит. | allowGigabit=true, строка port8-9,192.168.0.10,192.168.0.11,1000; 5000 мс в каждом направлении; 1% потерь, 2% недобора TX | failOnError=true, родитель stopOnError=true; штатная аварийная ветка сохранена | Загрузка, GraphCompiler, round-trip и параметры всех трёх вариантов в FullProfileSerializationTests |

Использована существующая Run Data Test. Она допускает скорость в каждой строке
portsText; новая нода не нужна. Другие пары остаются на 100 Мбит/с. Порядок,
ID и связи не меняются. Это целевое изменение текущего профиля, а не перенос
старой конфигурации с 1000 Мбит/с на всех портах. Исторический Qt не изменялся.

Нужен аппаратный прогон на двух гигабитных картах с Npcap, включая реальную
генерацию 1000 Мбит/с. Согласованный линк сам по себе не доказывает требуемую
пропускную способность. При недостаточной передаче тест должен отказать.
Ручная раскладка сохранена; общие конфликты ProfileLayout не исправлялись.
