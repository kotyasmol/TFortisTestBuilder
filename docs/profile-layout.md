# Размещение нод в сгенерированных профилях

После генерации JSON измерьте ноды через настоящий редактор Avalonia. Фиксированный
шаг сетки не учитывает длинные названия, параметры и поля конкретной ноды.

```sh
dotnet run --project tools/ProfileLayout/ProfileLayout.csproj -- --write profiles/example.json
dotnet run --project tools/ProfileLayout/ProfileLayout.csproj --no-build -- --check profiles/example.json
```

Можно передать несколько файлов. `--check` ничего не записывает: код возврата 0
означает отсутствие пересечений и достаточные отступы, 1 — нарушения размещения,
2 — ошибку загрузки/измерения. `--write` измеряет и размещает ноды, затем проверяет
результат. После него нужен отдельный `--check`, чтобы проверить повторную загрузку.

Утилита загружает профиль через `GraphSerializer` и отображает каждый граф в
headless-редакторе. Для каждого экземпляра берётся максимальный измеренный размер
в светлой и тёмной теме. Проверяются корневой граф и все вложенные `body`/`bodyGraph`.
Связь со стендом не устанавливается, граф не выполняется.

Начальные координаты задают порядок строк и нод в строке. Строки объединяются
по Y с точностью 1; ноды сортируются по X. При записи начало — (80, 80), отступ
между нодами — минимум 96 единиц графа, габариты округляются вверх до шага 16.
Следующая строка начинается ниже самой высокой ноды предыдущей. Размеры задаются
в координатах графа, а не экранных пикселях после масштабирования. Отдельная строка
аварийных действий остаётся отдельной. Утилита не прокладывает соединения в обход нод.

Меняются только `x`/`y` у нод. Исходное JSON-дерево сохраняет ID, связи, параметры,
оборудование, координаты областей платы, дату и неизвестные поля. Повторная обработка
уже размещённого файла не меняет координаты и не перезаписывает файл.

Для снимков задайте `TFORTIS_LAYOUT_ARTIFACTS` — каталог PNG корневого и первого
вложенного графа с пятью и более нодами. Просмотрите их после генерации: геометрическая
проверка не оценивает удобство ветвлений и смысловую группировку этапов.

Не запускайте `--write` для вручную расположенного пользовательского профиля без
задачи изменить его размещение. Изменение параметров, шаблонов или подписей может
изменить габариты; сгенерированные профили после таких изменений проверяются заново.

`tools/generate_rtl_profiles.py` вызывает размещение и повторную проверку автоматически.
Тесты: `ProfileLayoutTests` проверяют смешанные размеры, вложенные графы, сохранение
всех остальных данных, отсутствие конфликтов после загрузки и стабильность координат.

Сверка 2026-10-28: текущий обход измеряет корневой граф и тела составных нод.
Графы кнопок `quickActions` автоматически не обходятся; их размещение проверяйте
отдельно в редакторе. Это ограничение утилиты, а не подтверждение их геометрии.
