# Единая поставка через лаунчер

Требование пользователя: одна общая сборка, запуск и обновление на производстве
через корпоративный лаунчер. Remote — исключение для диагностики; отдельные DLL
и сборки под конкретный компьютер не являются способом выпуска.

Подготовка MAC, выбор одного/двух отправителей, граница времени передачи,
оценка основного замера и ожидание Modbus находятся в общем коде. Режим
зависит от профиля, фактического линка и измерения, а не от имени компьютера,
GUID конкретной карты или модели Realtek. Допуски профиля сохраняются.

COM, принтер, Stand ID и соответствие сетевых карт кабелям — локальные данные
рабочего места. Они не включаются в релиз. GUID карт не переносятся между ПК.
Для первичного определения портов и назначения адресов есть общий раздел «Сеть».

## Проверка из приложения

При открытии «Сеть» автоматически выполняется DataTestRuntimeCheck. Кнопка
«Проверить компьютер» повторяет проверку. Оператору не нужны права изменения
сетевых настроек; проверка не начинается во время теста или настройки стенда.

Показаны сборка, число pcap-карт, фактически загруженные wpcap/Packet DLL,
их версии и права запуска. Npcap распознаётся также в режиме совместимости
по метаданным библиотеки. Перечисление карт не подтверждает скорость: её,
потери и ошибки проверяет настоящий основной DataTest после включения изделия.
Проверка не устанавливает драйверы, не назначает адреса, не включает стенд,
не отправляет кадры и не меняет привязки или профиль.

## Драйверы Windows

Пользователь подтвердила отсутствие Npcap OEM. Обычный Npcap не включается
в ZIP; полностью тихая корпоративная установка недоступна. OEM предусматривает
такое развёртывание: https://npcap.com/oem/internal и
https://npcap.com/guide/npcap-users-guide.html.

Npcap и драйверы сетевых карт/USB/принтера остаются системными компонентами
Windows. Их однократная установка не требует другой сборки программы.
Нельзя обещать работу на любом неподготовленном оборудовании или автоматически
подменять драйвер всех сетевых карт пакетом, подобранным для одного Realtek.

## Выпуск

Используется штатный полный Windows ZIP с манифестом, контрольными суммами,
общим .NET, браузером и библиотеками. README начинается с корпоративного
лаунчера. Start-TestBuilder.cmd остаётся средством автономной инженерной
проверки и не создаёт серверную сессию.

Аппаратный прогон общего DataTest — [[48 - MAC-обучение и драйвер APK-03-06 2026-11-17]].
Новая проверка интерфейса не меняет этот алгоритм. ZIP сам по себе не означает
публикацию: нужны доступная Вышенская, проверенная копия сервера и загрузка
по [[28 - Сборка и публикация обновления]]. Профили сохраняются по её правилам.

## Проверка изменений

59 тестов общей диагностики, сети, ProfileUiIntegrity, RussianInterface и
DataTestMode прошли без пропусков. Отдельно прошли 8 проверок упаковщика.
Проверено распознавание Npcap в режиме совместимости, отсутствие ложной
готовности при нуле карт, доступ оператора без прав редактирования,
сохранность привязок и запрет пробы во время теста. Сетевой экран отрисован
в Headless Avalonia и просмотрен. Аппаратные команды не выполнялись.
