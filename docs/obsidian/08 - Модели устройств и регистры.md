# Модели устройств и регистры

Эта страница описывает модели устройств из `TestBuilder/Domain/Modbus/Models`. Модели создаются `SlaveManager` по значению регистра `0` найденного slave.

## Сводка моделей

Диапазон чтения рассчитан по `REG_START` и `REG_COUNT` внутри модели. Если в комментарии к коду и фактическому количеству есть расхождение, ориентироваться нужно на значение `REG_COUNT` и таблицу `RegisterItems`.

| Type register | Класс | DeviceType | Диапазон чтения |
|---:|---|---|---|
| `1` | `El60Model` | `EL-60` | `1000..1016`, `REG_COUNT=17` |
| `2` | `PS1Model` | `PS-1` | `1100..1114`, `REG_COUNT=15` |
| `3` | `PS2Model` | `PS-2` | `1200..1219`, `REG_COUNT=20` |
| `4` | `El60v5Model` | `EL-60v5` | `1400..1430`, `REG_COUNT=31` |
| `5` | `IO2Model` | `IO-2` | `1500..1529`, `REG_COUNT=30` |
| `6` | `StandRpsModel` | `Stand Rps` | `1300..1319`, `REG_COUNT=20` |
| `7` | `StandPwr180Model` | `PWR-Tester` | `1900..1952`, `REG_COUNT=53`; в UI-таблице также заведены `1953..1958` |
| `8` | `Ps3Model` | `PS-3` | `1200..1221`, `REG_COUNT=22` |
| `9` | `Simbat24Model` | `SIMBAT` | `1700..1716`, `REG_COUNT=17` |
| `10` | `Simbat48Model` | `SIMBAT` | `1700..1716`, `REG_COUNT=17` |

## RegisterItem

Каждый регистр представлен как:

| Поле | Назначение |
|---|---|
| `Address` | Modbus address. |
| `Name` | Человекочитаемое имя для UI. |
| `Value` | Текущее значение. |
| `IsReadOnly` | Можно ли писать через UI. |
| `Category` | Группа в таблице. |

`SlaveModelBase.SelectedRegister` игнорирует read-only регистры при выборе для записи.
