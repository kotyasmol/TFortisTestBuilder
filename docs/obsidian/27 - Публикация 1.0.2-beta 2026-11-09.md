## Профили и границы проверки

В `profile-templates` находятся:

- `PSW_UPS_Box_8x2Pro_parallel_start.json`;
- `PSW_2G6F_plus_full_algorithm.json`;
- `RTL_SW_board.json`;
- `RTL_POE_board.json`.

Комплект использует `profile-templates` и `testbuilder.defaults.json`.
Рабочие `profiles` и `testbuilder.settings` создаются приложением. При
автоматическом выборе папки копируются только недостающие шаблоны;
существующий одноимённый рабочий профиль не заменяется. Для обновления такого
профиля нужно сохранить его правки и отдельно выбрать/импортировать новый
шаблон. См. [[06 - JSON профили]]. Изменение серверного комплекта не подтверждает
миграцию пользовательских профилей на каждом клиентском компьютере.

Подтверждены сборка, перенос, Windows-проверка комплектности, резервная копия,
серверные хеши и маркер 5. Скачивание новой версии клиентским лаунчером,
аппаратный прогон и обновление dev-копии АПК03 в рамках этой публикации
не выполнялись. При первом клиентском запуске следует проверить фактическую
версию `1.0.2-beta`, выбранный профиль, его настройки SFP и настройки стенда.

Для отката сохранена полная предыдущая серверная копия. Откат не выполнялся.
Порядок получения возвращённой версии клиентом нужно проверять отдельно:
одного возврата файлов на сервер недостаточно для подтверждения обновления
всех рабочих мест.
