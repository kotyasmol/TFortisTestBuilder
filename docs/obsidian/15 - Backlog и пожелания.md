# Backlog и пожелания

Это единый список будущих работ. Записи со статусом `Кандидат` — технически
обоснованные предложения, но не обязательства и не принятые требования.

## Правило ведения

| Поле | Значение |
|---|---|
| ID | Стабильный номер `BL-XXX`. |
| Статус | `Кандидат`, `Запланировано`, `В работе`, `Готово`, `Отложено` или `Отклонено`. |
| Приоритет | `P0` — блокирует производство; `P1` — существенное снижение риска; `P2` — заметное улучшение; `P3` — идея. |
| Готово, когда | Наблюдаемый результат и требуемая проверка. |

Исторические пожелания помечаются выполненными; подробности реализации хранятся в
[[14 - Реестр решений]] и [[17 - Журнал проверок]].

## BL-010 — Программируемые кнопки с мини-графами

Дата запроса: 2026-10-19. Статус: **Готово в коде, 2026-10-28**.
Кнопки хранятся в профиле, создаются/редактируются на графе слева, копируются
вместе с профилем; в пульте находятся справа без редактирования. Есть цвет,
название, переключатель с двумя графами последовательных нажатий и индикатор
выполнения. Перед удалением показывается подтверждение. Выполнение независимо
от основного теста, с отдельными отменой и контекстом.
Источники: `TestViewModel.QuickActions.cs`, `ProfileActionViewModel`,
`ProfileActionEditorWindow`; проверки — `ProfileActionTests`, `ProfileActionViewTests`.
Порядок настройки — [[03 - Работа с приложением#Кнопки профиля]].
