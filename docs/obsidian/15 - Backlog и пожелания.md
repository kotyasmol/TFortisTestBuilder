# Backlog и пожелания

Это единый список будущих работ. Записи со статусом `Кандидат` — технически
обоснованные предложения, но не обязательства и не принятые требования.

## Правило ведения

| Поле | Значение |
|---|---|
| ID | Стабильный номер `BL-XXX`. |
| Статус | `Кандидат`, `Запланировано`, `В работе`, `Готово`, `Отложено` или `Отклонено`. |
| Приоритет | `P0` — блокирует производство; `P1` — существенное снижение риска; `P2` — заметное улучшение; `P3` — идея. |
| Готово, когда | Наблюдаемый результат и требуемая проверка. |

В этот файл не записываются уже реализованные изменения: для них используется
[[14 - Реестр решений]] и [[17 - Журнал проверок]].
