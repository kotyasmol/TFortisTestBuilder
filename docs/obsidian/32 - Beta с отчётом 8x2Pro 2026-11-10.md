# Beta с настройкой отчёта 8x2Pro от 10 ноября 2026

В beta `1.0.2-beta` добавлен вариант «параллельный старт · с проверкой SFP · отчёт 10.11».
В рабочем каталоге он появляется отдельным профилем. Базой для графа
служит выпущенный файл 09.11. Сверка JSON подтвердила исходные 19 корневых
нод, 17 связей, все вложенные графы, параметры и координаты. Изменены
идентификация варианта, дата, `reportTemplate` и маркер совместимости Start.
ProfileLayout подтвердил одинаковый результат в 21 графе.

В шаблоне выбраны 50 строк из образца 111, для которых есть данные исходного
графа. Строки без соответствующего измерения или проверки не подставляются.
Это касается тока нагревателей, 16 замеров под нагрузкой EL60 и
отдельного подтверждения детекции и перехода на АКБ. Для переменных
доступен поиск с флажками в «Состав отчёта… → Переменные».
Остальные три шаблона совпадают с предыдущим комплектом побайтно.
