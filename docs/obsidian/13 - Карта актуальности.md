# Карта актуальности

Эта заметка фиксирует, с чем сверялась Obsidian-документация при актуализации.

## Решение

`TestBuilder.slnx` содержит только:

| Проект | Назначение |
|---|---|
| `TestBuilder/TestBuilder.csproj` | Avalonia desktop-приложение. |
| `TestBuilder.Tests/TestBuilder.Tests.csproj` | xUnit-тесты runtime, serialization и monitoring. |

Удаленные Nodify-демо `Nodify.Calculator` и `Nodify.StateMachine` не описываются как часть проекта.

## Проверка после актуализации

Контрольные команды:

```powershell
rg -n "Nodify\.Calculator|Nodify\.StateMachine|Examples/Nodify" TestBuilder.slnx TestBuilder TestBuilder.Tests
dotnet build TestBuilder.slnx
dotnet test TestBuilder.slnx --no-build
```

Ожидаемый результат:

- поиск проектных ссылок на удаленные демо ничего не находит;
- сборка проходит без ошибок;
- тесты проходят без ошибок;
- предупреждения сборки не связаны с удаленными Nodify-демо.

В самих заметках точечные упоминания этих демо допустимы только как историческое пояснение, что они удалены и не входят в решение.
