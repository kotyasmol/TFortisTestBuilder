# Глоссарий

| Термин | Значение |
|---|---|
| Avalonia | Кроссплатформенный UI-фреймворк для .NET desktop-приложений. |
| Body graph | Вложенный граф составной ноды (`Subtest`, `For Slaves`). |
| Body Start | Техническая стартовая нода тела `For Slaves`. |
| Body End | Техническая конечная нода тела `For Slaves`, возвращает `Stop`. |
| COM-порт | Последовательный порт, через который приложение подключается к Modbus RTU стенду. |
| CompiledGraph | Результат компиляции visual graph в runtime graph. |
| Connector | Вход или выход ноды. В JSON связи хранят заголовки коннекторов. |
| DataTest | Сетевой тест передачи пакетов через пары адаптеров, реализован через SharpPcap. |
| DUT | Device Under Test, тестируемое устройство. |
| GraphCompiler | Сервис, который создает `TestNode` и привязывает переходы. |
| GraphSerializer | Сервис сохранения/загрузки графа в JSON. |
| GraphWorkspaceViewModel | Рабочая область графа с нодами, связями и выделением. |
| ITestStep | Контракт runtime-шага теста. |
| Modbus RTU | Протокол обмена с устройствами стенда через последовательный порт. |
| Nodify | Библиотека графового редактора. |
| NodeViewModel | Визуальная модель ноды в редакторе. |
| RegisterState | Хранилище последних известных значений регистров. |
| Slave | Modbus-устройство с конкретным slave ID. |
| SlaveManager | Сканирует устройства и создает модели slave. |
| SlaveRegistry | Singleton для передачи списка slave в ноды UI. |
| StepResult | Результат шага: `Next`, `True`, `False`, `Stop`. |
| TestContext | Общий runtime-контекст выполнения графа. |
| TestExecutor | Исполнитель runtime-графа. |
| TestNode | Runtime-узел графа, содержит step и переходы. |
| ZPL | Zebra Programming Language, язык печати этикеток Zebra. |
