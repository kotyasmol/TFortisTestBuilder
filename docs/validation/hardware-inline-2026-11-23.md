# Оборудование внутри основного окна — 23.11.2026

В пользовательском пути больше нет каскада окон. MainWindow размещает
HardwareEditorView на собственной странице; формы добавления устройств,
создания/редактирования шаблона и регистра временно заменяют её содержимое.
После «Назад» или отмены форма удаляется из дерева, состав остаётся черновиком.
Применение и отмена возвращают к прежнему рабочему разделу. Повторный вход
не создаёт ещё один экземпляр; основная навигация скрыта до выхода.

Для каталога оставлены основные поля, остальные раскрываются через «Все поля».
В редакторе шаблона идентификация раскрывается отдельно, область Modbus
отображается по-русски. Общая линия прокручивается внутри вкладки.

  место, русский интерфейс, справка, подключение и справка/оборудование в темах.
- 10/10 после визуальной правки колонки области: HardwareInlineWorkspaceTests
  и EquipmentLibraryTests.
- git diff --check без ошибок.

HardwareInlineWorkspaceTests проходит основной интерфейс при 1100×680 в двух
темах: сохранение размера, отсутствие OwnedWindows, повторный вход, четыре
открытия/отмены добавления, новый шаблон, пакет устройств, новый регистр,
применение и отмена следующего черновика. Сохранение шаблона и применение
состава проверяются как независимые операции. Тест использует временный
каталог; ошибочно созданная при первой версии теста единственная тестовая
запись местной библиотеки удалена по проверенному ID, последующие прогоны
используют изолированную библиотеку.

## Границы

Снимки получены штатным Avalonia Headless с настоящими контролами. Исходное
зависание на Маке не воспроизведено: запущенный ранее процесс уже завершился
с кодом 0 и не оставил ошибки в выводе. Это не доказательство устранения всех
причин зависаний. Устранён подтверждённый каскад диалогов и проверен новый путь.

Формат JSON, базовые карты, Modbus runtime и серверная публикация не менялись.
Ранее открытые редакторы профиля/каталога продолжают использовать те же
правила сохранения; справка обновлена вместе с интерфейсом.
