# Компактная сеть — 23.11.2026

Убран большой блок «Наборы, связь и компоненты». Наборы вынесены в компактное
меню; импорт, экспорт, сохранение и удаление находятся там же. Открытие меню
не меняет план; загрузка выполняется только выбором строки. После команды
меню закрывается, сообщение остаётся на странице.

Диагностика вызывается отдельной кнопкой. Показывается одна вкладка:
связь портов, поиск карты по кабелю, компоненты или журнал. На Маке оставлены
доступные поиск/журнал. Вложенных больших раскрывающихся секций нет.
Компоненты проверяются вручную. Отмена пробы доступна внизу страницы и при
скрытой панели. Состояние панели сохраняется в network/diagnostics;
прежние ключи cable/journal не удаляются из настроек, но больше не используются.

Счётчик карт больше не дублируется в трёх местах. Таблица занимает нужную
высоту до 440 px; при большом числе карт сохраняется прокрутка. Пустой статус
не занимает нижнюю панель. Сетевые алгоритмы, планы, привязки и парные проверки
не изменялись; автоматическая необязательная инспекция при входе в страницу убрана.
