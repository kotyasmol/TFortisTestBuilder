# Добавление пар в план сети — 2026-11-23

## Результат

В `Сеть → Тестовые порты и пары` доступна кнопка `Добавить пары…`.
Форма открывается на странице: количество пар, скорость 1–1000 Мбит/с,
сводка новых/итоговых портов. Названия, нумерация, назначение, маска и
начала обоих диапазонов находятся в `Названия и адреса`.

Каждая пара создаёт две строки в конце плана. За операцию — до 512 пар;
последующие группы дополняют список. Доступный диапазон определяется маской
и уникальностью основных/временных IP. Фиксированного предела пять пар нет.

На странице `Добавить пары` сохраняет дополненный план сразу. Прежние
строки, выбор карт и история применения сохраняются. Поиск/фильтр
сбрасываются, выделяется первый новый порт, таблица прокручивается в видимую
область. Отмена не записывает настройки. Ошибка ввода/записи оставляет форму
для исправления и повтора. Проверка снимка плана отклоняет форму, если за
время её редактирования план изменён другой командой.

В полном редакторе тоже есть `Добавить пары…`: используется та же форма
внутри этого окна. Результат, включая маску, возвращается в черновик;
запись настроек только по `Сохранить план`. Группы отдельных портов по-прежнему
доступны через `Добавить порты…`, общий UI выделен в `NetworkPortBatchEditor`.

Пары существующей ноды DataTest не меняются автоматически. Явное
`Взять пары из плана сети` копирует весь активный список, затем профиль
нужно сохранить. Для передачи плана остаётся экспорт/импорт сетевых наборов.

## Проверки

- 142 теста без ошибок: добавление пар, группы портов, большие планы,
  произвольные скорости, настройки/карты, меню сети, справка/экспорт,
  ProfileUiIntegrityTests, RussianInterfaceTests и DataTestModeTests.
- После правки прокрутки и высоты формы — 9/9 повторных UI-проверок и
  проверок справки. Новая строка целиком видна в окне; полный редактор
  использует доступную высоту без пустого отступа над формой.
- `NetworkPairAdditionTests`: реальные клики главной страницы в светлой и
  тёмной темах при 1100×800; повторный вход не создаёт вторую форму;
  owned-окон нет. К прежней паре добавлено 12 пар: 26 портов, 13 пар.
- Прежние поля и ссылки на сохранённые привязки/applied-владение сохраняются;
  settings перечитывается с диска, фильтр сбрасывается, выделяется новый порт.
  Нода меняет список только после явного импорта.
- Чистый план получает первую пару. Дробное количество и совпадающий IP
  отклоняются до записи. Отмена сохраняет содержимое файла побайтно.
- При внешней смене плана устаревшая форма отклоняется. Ошибка записи
  возвращает прежние ссылки и файл; повтор успешно сохраняет новые строки.
- В полном редакторе добавлено 150 пар и изменена маска на /16: после
  сохранения 302 порта, 151 пара; исходный план не меняется до сохранения.
- Встроенная справка обновлена: network, network-ports, network-fields;
  проверены поиск в нужном разделе и HTML-экспорт.

Новые тесты используют временный settings через CleanWorkstation. Приборы,
системные IPv4/DNS, рабочие настройки и пользовательские профили не менялись.
Передача трафика через 302 физических порта не выполнялась; проверена
структура плана и интерфейс. Релиз/серверная публикация не выполнялись.
