# Общие шаблоны и печать на АПК-03-07 — 2026-11-25

Нода выбирает сохранённый общий шаблон. Редактор ноды удалён из приложения;
исторический компонент оставлен только в тестах. Сохранение типа не пересоздаёт
редактор, вкладку, выделение и черновики других типов. Перетаскивание и стрелки
изначально заблокированы; колесо не меняет числовые поля без фокуса.

## Данные и совместимость

`labelTypeId` и переносимый `labelTemplate` сохраняются одним шагом Undo/Redo.
Явный ID имеет приоритет над привязкой модели. Новая печать читает актуальный
общий тип; при отсутствии ID в каталоге используется совпадающая вложенная
копия. Повтор не меняет снимок завершённого теста. Marker `Print Label (type v1)`
не позволяет прежней программе молча проигнорировать выбор или область печати.

`printAreaWidthDots` — отдельная ширина области принтера, не размер наклейки.
Явное значение делает калиброванные шаблоны независимыми от предыдущего задания.
Без него старый макет с ненулевым OriginX не сужает область командой Origin+Width;
для OriginX=0 используется ширина этикетки. Точные raw-снимки не переписываются.

## Физические пробы

Принтер TSC TE310, USB001, 300 dpi. Использован прежний размер макета 300×158
точек (25,4×13,4 мм). Во всех пробах данные последнего завершённого теста:
PSW+UPS-Box 8x2Pro, SN 00428, MAC C0:11:A6:20:01:AC, Code 128 `03200428`.
Новые серийные номера и серверные записи не создавались.

Первая серия V01–V10 (задания 14–23) обрезалась справа: исходные абсолютные
координаты были соединены с ошибочным сужением области до Origin+300.
Эту серию не принимать за результат. C01 (24) с областью 1248 точек обрезалась
слева; C02 (25) передвинута вправо на 7 мм. По обратной связи текст C03 (26)
сдвинут левее на 3 мм и ниже на 2 мм, код уменьшен. Пользователь подтвердила
адекватное положение текста C03 и попросила крупнее шрифт, теснее строки,
код левее на 4 мм и выше.

Исправленная серия R01–R10 (задания 27–36) учитывает эти указания. Общая
область 1248 точек, OriginX=523. Текст X=6/Y=26 относительно макета; шрифты
и последующие строки различаются. Код — модуль2, 158 точек ширины; X=46/58/70,
высота36–50, нижняя граница не ниже156. Каждый вариант отправлен одним RAW
заданием с `^PQ1`, без автоматических повторов. Очередь после серии пуста.
Номера R есть только на бумажной пробе, в производственном макете их нет.

Готовый переносимый каталог — `label-calibration-2026-11-25-types.json` рядом
с этим документом. В нём динамические источники и нейтральные образцы, а не
постоянные данные конкретного экземпляра. Калибровка горизонтальной области
относится к этому рабочему месту и ленте. Бумажный выбор лучшего R-варианта
и считывание производственным сканером требуют проверки пользователем.

На АПК резервные копии, исходные команды, матрица вариантов и журналы задания
находятся в `output/label-calibration-20261125` основной рабочей копии. Перед
обновлением дополнительно экспортировано несохранённое состояние текущего
профиля в `current-profile-memory-before-update.json`. Все пять исходных
профильных файлов совпали с резервными копиями по SHA256; эталоны не заменялись.
