# Настраиваемый список тестовых портов — 23.11.2026

Убрано автоматическое создание десяти адресов в BenchNetworkPlan. Новый план
пустой; сохранённый список загружается без изменения количества и параметров.
Пользователь задаёт количество групповым добавлением или создаёт порты по одному.
Подключение новой физической карты обновляет инвентаризацию без создания строк
и без переназначения прежних карт.

В «Сеть» доступны «Тестовые порты и пары…», пустое состояние и описание схемы.
У карты вкладка «Порт и пара DataTest» с созданием/удалением тестового порта.
Пустые поля скрыты до выбора порта; «Сохранить назначение» закреплено внизу.
Редактор всего списка позволяет удалить последнюю строку и все строки,
сохраняет пустой план. Системные IP и пары существующих профилей не меняются.

При удалении строк очищаются только исчезнувшие привязки; история владения
применёнными адресами остаётся до явной операции настройки Windows. Ошибка
сохранения откатывает план, привязки и историю. Если строки только добавляются,
прежние объекты привязок сохраняются. Начальные .2 — редактируемые предложения
первого адреса, а не обязательные строки. Размер определяется адресным
пространством и ресурсами, а не числом десять.

Проверки:

- 191 пройдена, 1 аппаратная пропущена без стенда: сетевые сервисы/UI,
  чистое рабочее место, целостность профилей, режимы DataTest, русский интерфейс,
  поиск и экспорт встроенной справки.
- 35/35 после уточнения подписей/пустого состояния, включая обе темы.
- 20/20 после закрепления сохранения и скрытия невыбранных полей.
- git diff --check без ошибок.

Новые сценарии: пустые настройки и JSON {}, планы 12/24/48/300, рост 12→13
адаптеров, удаление последнего/всех портов, сохранность applied-владения,
откат при ошибке записи и реальная форма в двух темах. Старый десятипортовый
сценарий проверяется явной тестовой заготовкой. Сохранённые профили, настройки
пользователя и сервер не переписывались; историческая совместимость старых
DataTest-профилей сохранена.
