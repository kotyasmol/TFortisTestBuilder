# Общие данные и содержимое профиля — 2026-11-23

## Расположение и сохранение

| Область | Точка входа | Содержимое и запись |
| --- | --- | --- |
| Каталог оборудования | Верхняя панель | Общие шаблоны устройств/регистров; собственные записи в `equipment-library.json`. Встроенные карты — из поставки. Создание/правка/перенос не меняют экземпляры профиля. |
| Оборудование текущего профиля | У графа, рядом с сохранением | Экземпляры, Slave, карты, Modbus, консоли. Над вкладками показано имя профиля. Применение в открытый граф, затем отдельное сохранение JSON. |
| Плата профиля | У графа, для типа «Плата» | Изображение и области текущего профиля. |
| Серия и этикетка, состав отчёта, пинг, аварийные действия | У графа | Метаданные проверки, сохраняемые с графом. |
| Настройки компьютера | Верхняя панель | Местные COM, принтер, сервер, Stand ID, папки, режим и тема. Независимы от JSON профиля. Резервный COM консоли доступен для обоих типов. |
| Сеть | Верхняя панель | Адаптеры и план этого рабочего места. Ноды DataTest получают пары отдельно, явным копированием. |
| Каталог этикеток | Настройки компьютера | Общие макеты; запись кнопкой «Сохранить каталог». В ручной печати — «Сохранить каталог и выбрать шаблон». |
| Макет ноды | «Выбрать / настроить шаблон…» в ноде | Окно «Этикетка ноды профиля», «Применить к ноде». Общий каталог не записывается; затем нужно сохранить профиль. |

Оборудование и каталог открываются внутри главного окна, формы встроены в
страницу. Повторный и отложенный вход не размножает страницы; одновременно
общий каталог, редактор оборудования и общие настройки не открываются.
Основные параметры JSON профилей не мигрируются. Справочник изделий сохраняет
существующий приоритет внешней карточки над резервной карточкой профиля при
использовании каталога; это отдельно описано в инструкции.

## Перенос оборудования

«Экспорт каталога…» выдаёт JSON `SchemaVersion=1`, `Entries` со своими
`EquipmentTemplate`. «Импорт каталога…» принимает этот формат и прежний
локальный массив. Предпросмотр показывает количество и названия добавлений/
обновлений. Запись выполняется только по «Импортировать в каталог».

Совпадающий ID обновляется, прочие записи сохраняются. Названия разных ID
не могут совпадать. Некорректные записи, неизвестная версия и устаревший
снимок отклоняются. Временный файл и атомарная замена сохраняют прежний файл
при неуспешной записи. Шаблон сохраняется со Slave=1; адрес экземпляра
назначается в профиле. Полный путь местного каталога показан в интерфейсе.

Формат отличается от `HardwareConfiguration` и
`reference/modbus/hardware-presets.json`. Для общего релиза требуется штатная
подготовка данных; экспорт не является публикацией. Инструкция PROD обновлена.

## Проверки

- 50 тестов: новый путь с нуля для коммутатора/платы, общий каталог,
  перенос/отмена, профильные экземпляры, встроенные формы, две темы,
  навигация и инструкция.
- 51 тест: печать, предпросмотр макетов, профильный режим редактора этикетки,
  независимость общего файла и поиск/HTML-экспорт справки.
- 70 тестов после разделения этикеток: ProfileUiIntegrityTests,
  RussianInterfaceTests, DataTestModeTests, сохранение рабочего окна,
  визуальные макеты, границы каталога/профиля и встроенная инструкция.
- Финальные 12/12 проверок после защиты от отложенных повторных переходов:
  общий каталог, профильная страница, настройки, рабочее окно и справка.
- EquipmentLibraryTransferTests проверяет объединение, обновление по ID,
  локальные записи, самостоятельный экземпляр, старый формат, дубликаты,
  неизвестную версию и устаревший снимок без записи.
- SharedCatalogScopeTests сравнивает открытый граф и байты сохранённого
  профиля до/после импорта общей карты. Каталог получает адрес регистра 20,
  профиль сохраняет свой адрес 10. Отмена не пишет файл.
- Профильная этикетка изменена и применена к ноде: исходный объект и байты
  `catalog/label-templates.json` сохранены.
- Встроенная инструкция: 82 статьи, новая `data-scopes`, обновлённые точные
  пути оборудования, платы, настроек и макетов. Проверены разделы и экспорт.

Тесты работают с временными каталогами и settings. Рабочие пользовательские
профили, карты поставки, реальное оборудование и сервер не обновлялись.
