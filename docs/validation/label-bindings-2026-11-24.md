# Типы этикеток и источники данных — 24.11.2026

В «Этикетки → Типы этикеток» добавлены «Новый тип» на основе выбранной
заготовки, «Создать копию», редактирование названия своего типа и вкладка
«Источники данных». Три универсальных состава остаются стартовыми.
В «Привязки изделий» модель выбирает тип отдельно от его редактирования;
«Сохранить привязки» действует на новые печати профилей этой модели.

Источники названия, полного/короткого SN, MAC, кода и шкафа независимы.
Доступны данные изделия/исполнения, настройки шага, переменная проверки,
постоянные название/код/шкаф и расчёт короткого номера по серии.
По умолчанию прежние настройки шага и проверки идентичности сохраняются.
Пустая/некорректная переменная блокирует задание, точный повтор не читает
новые источники. Ручная печать использует введённые SN/MAC.

Каталог v2 переносит types, assignments, baseTypeId и template.dataBindings.
v1 читается; импорт открывает черновики, сначала сохраняются типы,
затем назначения. Portable-профиль с источниками получает тип ноды
`Print Label (bindings v1)` для защиты от запуска в старом приложении.
Файлы профилей и местный пользовательский каталог не заменялись.
