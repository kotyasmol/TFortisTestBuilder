# Единый редактор этикеток — 25.11.2026

Причина каскада окон: кнопка PrintLabel-ноды вызывала LabelTemplatesWindow,
а его «Редактор элементов…» создавал LabelLayoutEditorWindow через ShowDialog.
Основной редактор типов уже был встроенным, но этот старый путь оставался.

Нода теперь открывает ProfileLabelEditorView в области GraphEditorView.
Шаблон выбирается над тем же LabelTemplateEditorView, который используется
общими типами. Отдельный LabelLayoutEditorWindow удалён; совместимый старый
каталог также встраивает общий компонент без дочернего окна.

Образец слева остаётся видимым на всех вкладках. Справа координаты и размеры
разложены до четырёх столбцов, источники — в два–три, данные пробы — в два.
Готовое содержимое выбирается через «Что печатать в элементе»; ручные формулы
показываются при выборе собственного формата. Сохранены перетаскивание/resize,
клавиши, копирование, центрирование, порядок печати, проба и экспорт PNG.
Убраны лишние отступы и повторная строка пояснения; внутренний раздел назван
«Шаблоны», рядом — «Привязки изделий».

Черновики шаблонов сохраняются при переключении. «Применить к ноде» заменяет
только профильную копию и поддерживает undo; «Отмена» не меняет её и каталог.
«Общие типы этикеток» возвращает к подходящему типу: назначенному модели либо
универсальному по составу. Сбрасываются мешающий поиск и вкладка привязок.
Общий тип сохраняется отдельно и имеет прежний приоритет при новой печати.
Форматы JSON и данные пользовательских/эталонных профилей не менялись.

Не представимая визуально команда остаётся доступна для правки в той же панели.
Также исправлено открытие постоянного названия с {{FitNameWidth}}: подгонка
использует буквальный текст; исходник сохраняется до явного применения.
При выборе состава без короткого SN поиск по серверному диапазону отключается
и для прежних шаблонов без внешней модели.
