# Демо подсветки платы

- `board-elements.svg` — шесть квадратов с ID `R1`, `R2`, `C1`, `C2`, `D1`, `U1`. Цвет каждого квадрата задаётся его атрибутом `fill`.
- `board-elements.png` — растровая копия той же схемы.
- `../../profiles/board_highlight_demo.json` — готовый автономный профиль «Проверка подсветки». Картинка и области уже встроены; для передачи достаточно одного JSON.

В текущем приложении ID из SVG автоматически не импортируются. Поэтому готовый профиль содержит PNG и шесть областей с совпадающими ID.

1. Выберите «Проверка подсветки» в редакторе или импортируйте JSON.
2. Перейдите в пульт, нажмите «Начать», затем «Плата». Окно платы можно оставить открытым для следующих запусков.
3. Пример работает примерно 13 секунд без стенда, сети и принтера. Во время шага соответствующий квадрат жёлтый.
4. R1, R2, C2 и D1 станут зелёными. C1 станет красным: отсутствие демонстрационной переменной намеренно вызывает отрицательный результат. U1 останется серым, поскольку его подтест отключён.

Зелёные результаты здесь получаются после задержек и не означают реальных измерений. Это только демонстрация подсветки. У C1 последовательно выполняются задержка и неуспешная проверка; оба шага привязаны к одному элементу.

Для ручного редактирования вернитесь в редактор и откройте «Плата». Области уже обведены; их коды и координаты можно изменить в таблице. В ноде кнопка «▧» задаёт связанные ID элементов. После изменений примените их к профилю и сохраните.
