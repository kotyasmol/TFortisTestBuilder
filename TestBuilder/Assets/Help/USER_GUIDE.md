# Пользовательская инструкция

Актуальная инструкция хранится в `user-guide.json` рядом с этим файлом.
Приложение показывает её как статьи с шагами и отдельными страницами нод.
«Настройки → Полная инструкция → Сохранить для печати…» экспортирует все
статьи в автономный HTML с содержанием и оформлением для печати.
